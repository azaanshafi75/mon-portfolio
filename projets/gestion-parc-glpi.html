Projet académique

Gestion de parc avec GLPI

Déploiement de GLPI pour centraliser l’inventaire, les utilisateurs, les équipements et les demandes de support.

GLPIGLPI InventoryApacheMariaDBLDAP
Version pratiquéeGLPI 11.0.4
ObjectifInventaire & support
TypeGestion de parc
01

Contexte

Le projet consistait à mettre en place un outil centralisé pour connaître le parc informatique et structurer la gestion des incidents.

02

Objectifs

  • Installer GLPI sur un serveur Debian.
  • Connecter la base MariaDB.
  • Déployer GLPI Inventory.
  • Faire remonter un poste Windows.
  • Préparer l’intégration des utilisateurs via LDAP.
03

Architecture GLPI

04

Mise en place

  • Installation d’Apache, PHP et MariaDB.
  • Création de la base et du compte de service.
  • Installation de GLPI et sécurisation des répertoires.
  • Installation du plugin GLPI Inventory.
  • Déploiement et configuration de l’agent sur Windows.
05

Difficultés rencontrées

  • Droits d’accès sur le répertoire des plugins.
  • Compatibilité entre versions de GLPI et du plugin.
  • Configuration de la remontée d’inventaire.
  • Préparation de l’authentification LDAP.
06

Compétences mobilisées

  • Administration d’une application web.
  • Base de données MariaDB.
  • Inventaire automatisé.
  • Gestion des permissions Linux.
